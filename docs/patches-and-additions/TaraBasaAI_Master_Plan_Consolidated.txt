FINAL, CONFIRMED ARCHITECTURE — NO MORE CHANGES AFTER THIS
------------------------------------------------------------

Database: Cloud Firestore. ONLY. Cloud SQL/MySQL is NOT used anywhere
in this project — that was in the original planning document before
we confirmed no account here can host a PHP server. Ignore any
reference to Cloud SQL/Laravel/Sanctum in older documents.

Auth: Firebase Authentication (Admin/Teacher/Parent email+password) +
a Cloud Function-issued custom token for Learner PIN access.

Notifications: Firebase Cloud Messaging. Free, unlimited, works fully
on the Spark (free) plan. No issue, no billing needed.

Reading audio: sent DIRECTLY inside the Speech-to-Text API request as
inline base64-encoded audio — NOT uploaded to Cloud Storage first.
This works because a Grade 1-3 reading passage is well under the ~1
minute / ~10MB limit for this method. This means Cloud Storage and
the Blaze billing plan are NOT required anywhere in this build.

Billing plan needed: SPARK (free) is sufficient for the entire
project as currently scoped. No credit card, no Blaze upgrade needed
for anything specified so far.

Cloud Functions: still needed (PIN verification, rate limiting,
status checks, the future Speech-to-Text/LLM calls) — Cloud Functions
themselves have a generous free quota on Spark (2M invocations/month)
and do NOT require Blaze at low usage. Only Storage specifically
required Blaze — that requirement no longer applies since Storage
isn't being used.
