Voice check

Open this page in the browser you use for TaraBasa. Press a button and listen. It uses only this computer's own read-aloud voice; nothing is sent anywhere.

1. Does A sound different from I?

The letter A used to be spelled "ay" for the voice. A Philippine English voice can read that like the Tagalog word "ay", which sounds like "eye". The app now uses the first spelling below. Listen to each one next to "eye" and tell me which one says the letter A properly.

For the letter A
For the letter I

Good: A sounds like the start of "eight" and I sounds like "eye". Not good: they sound the same, or A sounds like "uh" or "eh".
